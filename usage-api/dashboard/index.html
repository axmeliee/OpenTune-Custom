About these counts View more

Activity is based on reports received from participating OpenTune installations. It is not a count of unique people. Reinstalling or clearing app data creates a new installation identity. Offline, older or non-reporting apps may be missing; recent reports can arrive later.

All dates use UTC and both range endpoints are included. Zero means no reports received for that date during the recorded period. Dates before the first activity report are shown as unavailable, not zero. A failed request is also shown as unavailable.

Plays per active installation divides plays by distinct installations in the selected period. Daily active counts cannot be added to calculate unique users over a longer period.

Only aggregate counts are shown here. No song history, accounts, device names, IP addresses or installation identifiers are exposed by this dashboard. Website counters and GitHub download events are separate measures and should not be combined.
