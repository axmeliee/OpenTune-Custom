# OpenTune Custom: установка и обновления

Неофициальная сборка [OpenTune](https://github.com/justshivv/Opentune), GNU GPL v3. Код оригинала и авторство сохранены. Функция **New songs first** относится только к локальным плейлистам.

## Скачать

[Последний кастомный релиз](https://github.com/axmeliee/OpenTune-Custom/releases/latest). Выбери файл `OpenTune-v…-custom.1-universal.apk`; он подходит всем поддерживаемым архитектурам Android. Требуется Android 8.0 или новее.

Идентификатор приложения — `com.opentune.custom`. Новые сборки подписываются прежним ключом Custom, поэтому рассчитаны на установку поверх старой Custom с сохранением данных. Официальное приложение имеет другой идентификатор и устанавливается отдельно. Первая установка этой обновлённой Custom выполняется вручную; уже установленная старая Custom ещё проверяет официальный репозиторий и сама новый канал не обнаружит.

Открой скачанный APK и подтверди установку в Android. При необходимости разреши установку выбранному браузеру или файловому менеджеру. Перед первой заменой рекомендуется экспортировать данные через **Settings → Storage and data → Export data**. Удалять старую Custom для обновления не требуется.

## Кнопка

Открой локальный плейлист в Library, включи **New songs first**. Новые песни будут добавляться в начало, группа сохраняет свой порядок, дубликаты пропускаются, существующие песни не переставляются. Выключение возвращает добавление в конец. Та же настройка есть в **Settings → Library → Songs and lists → Add new songs to start**.

Синхронизируемые и онлайн-плейлисты продолжают использовать порядок оригинального приложения. Кнопка там скрыта.

## Автоматические обновления

После установки новой Custom проверка обновлений внутри приложения использует `axmeliee/OpenTune-Custom`. Включи **Settings → About → Check for updates automatically**; вручную проверить обновления можно в том же разделе. Android потребует подтверждение установки.

GitHub Actions проверяет стабильные релизы оригинала каждые шесть часов. Новый релиз строится из точного исходного коммита оригинала с `custom/app.patch`, проходит целевые проверки, подписывается постоянным ключом и публикуется со своими исходниками и `SHA256SUMS.txt`. Уже выпущенная версия повторно не собирается. Ошибка переноса или проверки останавливает публикацию; произвольные будущие изменения оригинала могут потребовать ручного исправления патча.

Расписание GitHub может задерживаться. GitHub также отключает расписания публичных репозиториев после 60 дней без активности; состояние нужно проверять на [странице Actions](https://github.com/axmeliee/OpenTune-Custom/actions/workflows/custom-release.yml). Сам APK не требует работающего компьютера для поиска и загрузки опубликованного обновления.

## Проверяемость

Каждый релиз содержит исходный тег, upstream-коммит, контрольную сумму патча и APK. Ключ подписи не должен находиться в исходниках, патче, артефактах или логах. Он хранится отдельно; для облачной сборки используются GitHub Actions secrets.

Фактические результаты текущей проверки перечисляются в итоговом отчёте выполнения. Наличие этого документа не подтверждает успешный запуск Actions или установку на телефон.
